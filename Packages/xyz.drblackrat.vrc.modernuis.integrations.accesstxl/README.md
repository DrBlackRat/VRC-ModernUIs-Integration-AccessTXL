# What is the ModernUIs AccessTXL Integration?

Integration to allow using AccessTXL for ModernUIs Whitelist / Permission system, as well as the other way around.

### AccessTXL

Documentation: https://vrctxl.github.io/Docs/docs/access-txl

GitHub: https://github.com/vrctxl/AccessTXL

### ModernUIs

GitHub: https://github.com/DrBlackRat/VRC-ModernUIs

# How to use it

You can add the AccessTXL To Whitelist Bridge Prefab, as well as the Whitelist To AccessTXL Bridge Prefab to your scene under: 

`Tools > DrBlackRat > ModernUIs Integrations > AccessTXL`
